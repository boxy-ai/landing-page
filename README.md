# Meet Boxy

Landing page source for Boxy.

## Running the code

Run `mise trust` to trust the local `mise` configuration.

Run `mise install` to install the pinned toolchain.

Run `pnpm install` to install dependencies.

Run `pnpm dev` to start the development server.

Run `pnpm lint` to lint the project with `oxlint`.

Run `pnpm format` to format the project with `oxfmt`.

Run `pnpm typecheck` to run TypeScript checks.
